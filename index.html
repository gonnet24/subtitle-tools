주요 기능

SMI · SRT · VTT 변환

국내에서 많이 쓰는 SMI와 표준 SRT, 웹용 VTT를 서로 변환합니다.

ASS/SSA 읽기

ASS/SSA의 대사 구간을 읽어 SRT, SMI, VTT로 변환합니다.

전체 싱크 조절

+1.5초 또는 -2초처럼 전체 자막 시간을 한 번에 앞뒤로 이동합니다.

한글 인코딩 지원

UTF-8 또는 CP949/EUC-KR로 파일을 읽을 수 있습니다.

브라우저 내부 처리

파일 내용을 별도 서버로 보내지 않고 현재 브라우저 안에서 처리합니다.

즉시 다운로드

변환 완료 후 결과를 파일로 저장하거나 클립보드에 복사할 수 있습니다.

사용방법

1. 자막 파일을 선택합니다. 한글이 깨지는 SMI는 파일 인코딩을 CP949/EUC-KR로 바꿔 다시 읽으세요.
2. 출력 형식과 필요한 경우 싱크 조절 값을 선택합니다.
3. 변환하기를 누르고 결과를 확인한 뒤 다운로드합니다.

자주 묻는 질문

자막 파일이 서버로 올라가나요?

아니요. 현재 버전의 변환 기능은 브라우저에서 실행되며 선택한 자막 파일을 별도 서버에 저장하지 않습니다.

SMI 한글이 깨져요.

파일 인코딩을 CP949/EUC-KR로 선택하고 파일을 다시 불러오세요. 오래된 국내 SMI 파일은 CP949로 저장된 경우가 많습니다.

ASS 스타일도 그대로 보존되나요?

현재 ASS/SSA는 대사 내용과 시간 구간 중심으로 변환하며 글꼴, 위치, 색상 같은 고급 스타일은 출력 형식 특성상 보존하지 않습니다.

싱크 -1.0은 무슨 뜻인가요?

모든 자막을 1초 앞당깁니다. +1.0은 1초 늦춥니다.
